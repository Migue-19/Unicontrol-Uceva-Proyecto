Fase en desarrollo
## Reglas de Colaboración

Para el desarrollo del proyecto **UCEVA UniControl** se utilizará el flujo de trabajo **GitHub Flow**, el cual permite mantener un desarrollo organizado y colaborativo.

### Flujo de trabajo

1. La rama principal del proyecto es **main**.
2. Ningún desarrollador puede realizar cambios directos sobre la rama **main**.
3. Cada nueva funcionalidad debe desarrollarse en una nueva rama.

Ejemplo de ramas:

- feature/solicitud-materias
- feature/notificaciones
- feature/historial-solicitudes

### Proceso de trabajo

1. Crear una nueva rama desde **main**.
2. Realizar los cambios necesarios en esa rama.
3. Subir los cambios al repositorio.
4. Crear un **Pull Request** hacia la rama **main**.
5. El Pull Request debe ser revisado por al menos un miembro del equipo antes de aprobarse.

### Reglas adicionales

- Todo cambio debe pasar por revisión.
- Se debe mantener un código claro y documentado.
- No se permiten cambios directos en la rama principal.

Este flujo garantiza un desarrollo seguro, organizado y colaborativo para el proyecto.
